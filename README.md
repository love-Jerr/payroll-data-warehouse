# 教职工薪资数据仓库设计与ETL开发

## 项目背景
校内薪资核算涉及多部门、多薪资项，手工汇总效率低且易出错。本项目旨在建设规范化数据仓库，支持自动化对账与多维分析，直接支撑财务部门异常数据溯源与薪资结构分析。

## 技术栈
- **数据库**：SQL server
- **开发语言**：Java，JDBC
- **数据处理**：存储过程、触发器、Power Query
- **分析展示**：Excel Power Pivot

## 数仓架构设计(ODS -> DWD -> DWS)
本项目采用星型模型设计，覆盖10+张表。

- **ODS 层**：接收原始薪资数据，保留脏数据与错误记录，不做清洗。
- **DWD 层**：维度表 + 事实表 + 汇总表，完成清洗、去重、维度关联与应发/实发计算。
- **DWS 层**：面向分析场景的月度汇总表与部门汇总视图，支撑报表输出。
- **ETL 层**：批次管理，记录每次抽取的执行状态。
- **AUDIT 层**：数据质量检查结果，覆盖空值率、重复记录等规则。

## 核心工作与成果
1. **数仓建模与分层**：设计星型模型(事实表：薪资核算流水；维度：员工、部门、薪资项目、时间)，规划三层架构，输出完整数据字典。
2. **ETL开发与数据质量保障**：
   - 编写存储过程实现增量抽取、清洗及月度自动汇总。
   - 设计触发器+约束实现应发/实发自动计算，引入事务机制保证批量更新一致性。
   - 制定数据质量监控规则(记录数波动、空值率)，定期产出质量报告。
3. **业务分析与报表输出**：基于 DWS 层开发部门、月份、工号组合查询，利用Excel Power Pivot搭建动态透视表，自动生成月度对账报表。

## 项目成果
- 建成覆盖 **10 张物理表 + 2 个视图** 的薪资数据仓库，分布在 5 个 Schema 中。
- 经流程拆解估算，人工核算时间可 **缩短约 60%**（重复性环节自动化，异常排查仍需人工介入）。
- 交付 SQL 脚本共 13 个文件，覆盖建库、建表、ETL、触发器、质量监控与测试数据。
