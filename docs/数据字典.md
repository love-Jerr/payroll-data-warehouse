## 一、薪资计算公式

| 指标 | 计算公式 |
|---|---|
| 应发工资 | 基本工资 + 岗位津贴 + 绩效奖金 + 其他应发 |
| 扣款合计 | 社保 + 公积金 + 个税 + 其他扣款 |
| 实发工资 | 应发工资 - 扣款合计 |

## 二、核心表清单

| 层级 | 表名 | 说明 |
|---|---|---|
| ODS | `ods.salary_raw` | 原始薪资数据 |
| ODS | `ods.salary_error` | 错误记录 |
| DWD | `dwd.dim_department` | 部门维度 |
| DWD | `dwd.dim_employee` | 员工维度 |
| DWD | `dwd.dim_salary_item` | 薪资项目维度 |
| DWD | `dwd.fact_salary_detail` | 薪资明细事实表 |
| DWD | `dwd.salary_calculation` | 薪资核算汇总表 |
| DWS | `dws.employee_month_salary` | 员工月度薪资汇总 |
| ETL | `etl.import_batch` | ETL 批次管理 |
| AUDIT | `audit.data_quality_result` | 数据质量检查结果 |

> 说明：时间维度及部门月度汇总以视图形式实现，详细字段定义见 `sql/` 目录下的建表脚本。
